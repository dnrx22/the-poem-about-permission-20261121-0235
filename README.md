A short original poem about agency — the power to ask and to be given. The program is a small, deterministic Python script (standard library only, no network) that writes the poem to `/output/entry.txt`. The poem is 225 characters: a door that was only wood until a knock turned its threshold into a handshake, and every yes received carried like a key that was never stolen.

## Run it

```sh
python3 main.py
```
